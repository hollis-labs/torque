# Designer Context — Clockwork Manifold

> Project-specific design conventions. Loaded by the designer agent role.

## Stack

- **Components:** shadcn/ui v4
- **Styling:** Tailwind CSS v4
- **Icons:** lucide-react

## Design Principles

- Desktop-first — this is a developer tool, not a consumer app
- Information density over whitespace — dashboards, tables, task views
- shadcn/ui as the component foundation — extend, don't replace
- Consistent with shadcn patterns: variants, sizes, composable primitives
